## ​ Getting Started

```bash
# 1) Clone the repository
git clone https://github.com/miladmo68/Shopping-Cart.git
cd Shopping-Cart

# 2) Install dependencies
npm install

# 3) Start development server
npm run dev

# 4) Build for production
npm run build
